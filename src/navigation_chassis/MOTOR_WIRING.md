# 电机 + 编码器 接线说明（Raspberry Pi 5）

> 对应脚本：`/home/zs/test_motor_encoder.py`
> 电机驱动：L298N 类双 H 桥模块 · 编码器：增量式（正交）A/B 相
> 状态：**已真机验证**——开机自检 `PASS`、直行 PID tick 差 <6（match ≈100%）、A/D 转向与物理左右一致。

GPIO 编号均为 **BCM** 编码，括号内为 40P 排针的**物理引脚号**。

---

## 1. 端口分类总览

| 类别 | 信号 | BCM GPIO | 物理引脚 | 方向 | 说明 |
|---|---|---|---|---|---|
| **PWM 控制（输出）** | Left  PWM | GPIO12 | Pin 32 | Pi → 驱动板 | 左轮速度（硬件 PWM0） |
| **PWM 控制（输出）** | Right PWM | GPIO13 | Pin 33 | Pi → 驱动板 | 右轮速度（硬件 PWM1） |
| **方向控制（输出）** | Left  DIR | GPIO27 | Pin 13 | Pi → 驱动板 | 左轮正/反转 |
| **方向控制（输出）** | Right DIR | GPIO23 | Pin 16 | Pi → 驱动板 | 右轮正/反转 |
| **编码器反馈（输入）** | Left  ENC (B相/脉冲) | GPIO20 | Pin 38 | 编码器 → Pi | 左轮计数脉冲 |
| **编码器反馈（输入）** | Right ENC (B相/脉冲) | GPIO21 | Pin 40 | 编码器 → Pi | 右轮计数脉冲 |
| 编码器反馈（输入，未使用） | Left  ENC A相 | GPIO5 | Pin 29 | 编码器 → Pi | 正交 A 相，当前脚本未采样 |
| 编码器反馈（输入，未使用） | Right ENC A相 | GPIO6 | Pin 31 | 编码器 → Pi | 正交 A 相，当前脚本未采样 |

- **控制类（Pi 输出）**：`GPIO12 / GPIO13`（PWM 调速）+ `GPIO27 / GPIO23`（DIR 换向）——共 4 个。
- **反馈类（Pi 输入）**：`GPIO20 / GPIO21`（左右轮编码器脉冲计数）——脚本实际只用这两路；A 相 `GPIO5 / GPIO6` 已布线但代码未用（如需判向/4 倍频可启用）。
- 编码器输入在脚本中配置为**上拉输入**，后台线程以 ~150kHz 忙等轮询检测上升沿。

## 2. 电机控制真值表（L298N 侧）

| 动作 | PWM 引脚 | DIR 引脚 |
|---|---|---|
| 前进 Forward | duty（0–100%） | 0 |
| 后退 Reverse | 0 | 1（满速） |
| 停止 Stop | 0 | 0（滑行） |
| 刹车 Brake | high | 1 |

- PWM 频率：`1000 Hz`，占空比范围：`0–100`（百分比）。
- 后退在代码里恒为满速（不调速）。

## 3. 左右配对与物理修线记录（重要）

**曾发现的问题**：电机驱动侧与编码器反馈侧的**左右配线交叉**——
`L_PWM(GPIO12)` 驱动的轮子，其编码器脉冲原本接在 `GPIO21`（右）上，
`R_PWM(GPIO13)` 驱动的轮子编码器接在 `GPIO20`（左）上。

后果：直行闭环 PID 变成**正反馈**（压低某侧 PWM，该侧编码器读数反而飙升），
两侧 PWM 双双撞钳位、越漂越大（tick 差 ~3500）。

**处理（源头修复）**：已将**两根编码器信号线物理对调**（`GPIO20 ↔ GPIO21`），
电机电源线不动。修复后代码引脚定义即真实、正确的配对：

```python
L_ENC = 20   # 左轮编码器脉冲（已与左电机同侧）
R_ENC = 21   # 右轮编码器脉冲（已与右电机同侧）
```

**验证方式**：开机自动运行 `_pairing_selfcheck`（或按 `C` 重跑）；
`--no-selfcheck` 可跳过。自检会打印 `[pair] ✓ CORRECT` 与 `SelfCheck PASS`。
> 今后换线/重新组装后，只要看开机那行 `SelfCheck PASS` 即可确认没接反。

## 4. 机械 / 编码器标定常数

| 参数 | 值 | 说明 |
|---|---|---|
| `WHEEL_RADIUS` | 0.033 m | 车轮半径 |
| `TICKS_PER_REV` | 2300 | 每圈编码器脉冲数（标定值，实测约 2100–2500） |
| `PWM_FREQ` | 1000 Hz | PWM 频率 |
| `PWM_RANGE` | 100 | 占空比满量程（百分比） |

距离换算：`distance = ticks × 2π·WHEEL_RADIUS / TICKS_PER_REV`。

## 5. 接线示意

```
                          Raspberry Pi 5 (40P)
   ┌──────────────────────────────────────────────┐
   │  Pin32 GPIO12 ── L_PWM ─┐                     │
   │  Pin13 GPIO27 ── L_DIR ─┤──► 左电机(L298N A) │
   │  Pin33 GPIO13 ── R_PWM ─┐                     │
   │  Pin16 GPIO23 ── R_DIR ─┤──► 右电机(L298N B) │
   │                          │                     │
   │  Pin38 GPIO20 ◄── L_ENC ─┼── 左轮编码器B相    │  ← 已与左电机同侧(修线后)
   │  Pin40 GPIO21 ◄── R_ENC ─┼── 右轮编码器B相    │
   │  Pin29 GPIO5  ◄── A相(左, 未用)               │
   │  Pin31 GPIO6  ◄── A相(右, 未用)               │
   └──────────────────────────────────────────────┘
        输出(Pi→板)：GPIO12/13 调速，GPIO27/23 换向
        输入(编码器→Pi)：GPIO20/21 计数（上拉，上升沿计数）
```

## 6. 测试项速查（脚本按键）

| 键 | 功能 |
|---|---|
| `W` | 直行（PID 闭环，速率差 PI，相等基础 50%、±trim） |

| `4` | 开环直行对比（两轮同 duty，无 PID，判断直行快慢的正确测法） |
| `C` | 重跑接线自检（配对 + 方向） |
| `I` | 打印 GPIO 电平 |
| `Q` | 退出 |
